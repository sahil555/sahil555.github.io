## 🔧 Customization Guide

### Change Colors
1. Open `assets/css/style.css`
2. Find line ~1010: `:root { --primary-color: ...`
3. Update `#18d26e` to your preferred color
4. All components update automatically

### Add Projects
1. Open `index.html`
2. Find the Projects section (~line 490)
3. Copy a project-card block
4. Update project details and links

### Update Skills
1. Open `index.html`
2. Find Skills section (~line 155)
3. Add/remove progress bars
4. Update percentage values

### Modify Interests
1. Open `index.html`
2. Find Expertise Areas section (~line 315)
3. Edit descriptions
4. Change icons if needed

## 📞 FAQ

**Q: How do I add my resume?**
A: Place your PDF at `assets/files/Sahil_Kureel_Resume.pdf` and both download buttons will work.

**Q: Can I change the colors?**
A: Yes! Edit CSS variables at line ~1010 in `assets/css/style.css`.

**Q: How do I add more projects?**
A: Copy a project-card section in the Projects area and update the content.

**Q: Do I need to update project links?**
A: Only if you want them to point to different URLs. Current links are to your actual projects.

**Q: Is the design mobile-friendly?**
A: Yes! Fully responsive and tested for mobile, tablet, and desktop.

**Q: How do I customize the theme?**
A: See COLOR_SCHEME.md for detailed color and styling reference.
